# Your Expansion, All in One Place

The Forge installation kit now includes a complete offline news library. Read the full expansion overview, browse individual updates, and jump directly to the feature you want to learn about without leaving the installer.

## Complete expansion notes

The main article covers Forge's unlock, every active ability and upgrade, all three passives, Cannon Wheel, Item Exchange, Prism Jackpot, the new Aspects, Ascendant, shared item limits, music, controller support, and the presentation and performance work included so far.

## A home for future expansions

Articles are grouped by expansion. Complete expansion notes and individual updates have separate entries, so new releases can join the library while earlier articles remain available. Every entry shows its type, date, and version. Sections can be selected directly, and the full article can be copied for sharing.

The same source articles are bundled with the Linux testing kit as readable Markdown notes. Everything needed to read them ships in the kit; there is no web account, remote news feed, or additional browser component to install.

## Gameplay compatibility

This is **installer version 0.15.3**, containing **gameplay version 0.15.2**. It changes the installer and its documentation. Forge balance, unlocks, items, Aspects, networking, and the latest gentler Ascendant rules are unchanged. Co-op players already using gameplay 0.15.2 remain compatible.
